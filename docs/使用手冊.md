## 4. 照片分類工具

### 概述

Web-based 照片分類工具，用 Python 內建 HTTP server 提供網頁介面。
逐張預覽 `MyPhotos/` 中的照片與影片，快速分類到各貓咪資料夾。

### 啟動方式

```bash
cd MyWebsite
python3 tools/photo-manager.py
```

瀏覽器開啟 **http://localhost:9090**

### 操作方式

#### 按鈕

| 按鈕 | 快捷鍵 | 動作 |
|------|--------|------|
| 🐱 波波 | `1` | 移動到 `photos/波波/` |
| 🐱 米米 | `2` | 移動到 `photos/米米/` |
| 🐱 豆豆 | `3` | 移動到 `photos/豆豆/` |
| 🐱 小寶寶 | `4` | 移動到 `photos/小寶寶/` |
| 🐾 多隻貓 | `M` | 彈出複選框（勾選多隻貓 → 複製到各資料夾） |
| 📁 保留 | `K` | 移動到 `photos/_保留/` |
| 🗑️ 刪除 | `D` | 移動到 `photos/_已刪除/` |
| ⏭ 跳過 | `S` | 跳過此檔（移到列表末尾，稍後再處理） |
| ↩ 復原 | `Z` | 撤銷上一步操作 |

#### 工作流程

```
MyPhotos/ 中的檔案 → 預覽 → 按分類鍵 → 檔案移動到 photos/<分類>/
                                         ↓ 多貓複選
                                    複製到每個選中的貓資料夾，原檔刪除
```

### 支援格式

| 類型 | 格式 |
|------|------|
| 圖片 | JPG, JPEG, PNG, GIF, WebP, BMP, **HEIC**（自動轉 JPEG 預覽） |
| 影片 | MP4, MOV, AVI, MKV, M4V, WebM |

### 注意事項

- **HEIC 檔案**：首次預覽會用 macOS `sips` 轉 JPEG（約 1-2 秒），之後有快取
- **大型 MOV**：影片只載入 metadata 不自動下載，按分類鍵會先停止影片再送 API
- **卡住的影片**：按 `S` 跳過，移到末尾稍後處理
- **同名檔案**：目標資料夾已有同名檔時，自動加 `_1`, `_2` 後綴
- **復原**：只能復原最後一步

### 新增分類

若需要新增分類（如「全家福」），修改 `tools/photo-manager.py`：

```python
CATEGORIES = {
    "bobo":    "波波",
    "mimi":    "米米",
    "doudou":  "豆豆",
    "baby":    "小寶寶",
    "family":  "全家福",     # ← 新增
    "keep":    "_保留",
    "delete":  "_已刪除",
}
```

然後在 HTML 中新增對應按鈕和鍵盤快捷鍵即可。

## 5. 飲食日記系統

### 概述

`cat-diary.html` 提供互動式貓咪飲食紀錄，資料存在瀏覽器 `localStorage`（無需後端）。

### 管理員模式

| 模式 | 密碼 | 功能 |
|------|------|------|
| 訪客 | 不需要 | 只能查看紀錄 |
| 管理員 | `jimmy2026` | 可新增/刪除紀錄、匯入/匯出 |

- 管理員登入後存在 `sessionStorage`，關閉分頁自動登出
- 密碼以 SHA-256 hash 儲存在程式碼中

### 功能

- 📝 新增飲食紀錄（日期/時間/貓咪/類型/食物/份量/備註）
- 📊 Chart.js 近 7 天堆疊長條圖
- 📋 今日摘要（每隻貓進食次數 & 總量）
- 🔍 篩選（依貓咪 / 類型）
- 💾 匯出 / 匯入 JSON 備份

### 資料備份

```
管理員模式 → 「匯出 JSON」按鈕 → 下載備份檔
```

匯入：「匯入 JSON」→ 選擇檔案 → 覆蓋現有資料

> ⚠️ 資料僅存在瀏覽器中，清除瀏覽資料會遺失！定期匯出備份。

## 6. Python 工具腳本

### 環境需求

- **Python 3.9+**（macOS 內建即可）
- 無需安裝額外套件（全部使用標準庫）
- HEIC 轉檔依賴 macOS 內建 `sips`

### 腳本列表

| 腳本 | 用途 | 用法 |
|------|------|------|
| `tools/photo-manager.py` | 照片分類 Web UI | `python3 tools/photo-manager.py` |
| `update-photolist_json.py` | 掃描 photos/ 更新 photo-list.json | `python3 update-photolist_json.py` |
| `convert_heic_batch.py` | HEIC → JPG 批次轉檔 | `python3 convert_heic_batch.py` |

### 更新相片清單

每次照片有變動後，執行：

```bash
python3 update-photolist_json.py
```

會掃描 `photos/` 目錄，更新 `photo-list.json`，供 `photo-gallery.html` 讀取。

## 7. 日常維護指南

### 新增照片

```bash
# 1. 將新照片放入 MyPhotos/
cp ~/Desktop/新照片/*.jpg MyPhotos/

# 2. 啟動分類工具
python3 tools/photo-manager.py

# 3. 在瀏覽器分類完成後，更新相片清單
python3 update-photolist_json.py

# 4. 提交變更
git add photos/ photo-list.json
git commit -m "feat: 新增 XX 張照片"
git push
```

### 修改頁面內容

1. 編輯對應 HTML 檔案
2. 樣式修改在 `css/style.css`
3. 共用行為修改在 `js/common.js`
4. 本機預覽：用任何 HTTP server（如 `python3 -m http.server 8000`）

### Git 操作規範

```bash
# 提交前必做
git status
git diff

# 確認 remote
git remote -v

# Commit message 格式
git commit -m "feat: 簡短描述"    # 新功能
git commit -m "fix: 簡短描述"     # 修復
git commit -m "docs: 簡短描述"    # 文件
git commit -m "style: 簡短描述"   # 樣式
```

### 清理已刪除照片

```bash
# 確認 _已刪除/ 的內容
ls photos/_已刪除/

# 確認無誤後永久刪除
rm -rf photos/_已刪除/*
```

## 10. 常見問題 FAQ

### Q: HEIC 照片無法預覽？
**A:** 分類工具已支援自動轉檔。如果仍然無法預覽，確認 macOS 有 `sips` 指令（內建應該都有）。首次轉檔需 1-2 秒。

### Q: MOV 影片卡住怎麼辦？
**A:** 按 `S`（跳過）直接跳到下一張。影片改為只載入 metadata，不會自動下載全檔。按分類鍵時會先停止影片下載再送出 API。

### Q: 飲食日記資料不見了？
**A:** 資料存在瀏覽器 localStorage。清除瀏覽資料或換瀏覽器就會遺失。建議定期用管理員模式的「匯出 JSON」備份。

### Q: 分類錯了怎麼辦？
**A:** 立刻按 `Z` 可復原上一步。如果已經過了很多張，手動去 `photos/<錯誤資料夾>/` 把檔案移回 `MyPhotos/` 重新分類。

### Q: 如何在手機上用分類工具？
**A:** 手機和電腦連同一個 WiFi，在手機瀏覽器輸入 `http://<電腦IP>:9090`。但鍵盤快捷鍵不可用，只能點按鈕。

### Q: photos/ 根目錄有散落的 JPG？
**A:** 那是早期遺留的 6 張照片（IMG_0006 等），可以手動移到適當分類或刪除。

### Q: 怎麼新增更多照片？
**A:** 把新照片放入 `MyPhotos/` 資料夾，然後執行 `python3 tools/photo-manager.py` 開始分類。
